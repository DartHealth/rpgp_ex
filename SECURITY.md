# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: on this repository's **Security** tab,
choose **Report a vulnerability**. Don't open a public issue.

We aim to acknowledge a report within five working days.

A vulnerability in OpenPGP parsing or cryptography itself is usually in
[rPGP](https://github.com/rpgp/rpgp). If you can tell, report it to rPGP as well.

## Supported versions

Only the latest release receives fixes.
